**Tech:** `RAG` `LangChain` `LLMs` `Embeddings` `Vector Search` `Python`

🔗 **[View Project](https://github.com/IT24102884/Sri-Lanka-gov-rag-assistant)**

---

### 🐾 Animal Image Classification System

A full-stack image classification application using **EfficientNet-B2 transfer learning**. The trained PyTorch model is served through a FastAPI backend and integrated with a React frontend.

**Tech:** `PyTorch` `EfficientNet-B2` `Transfer Learning` `FastAPI` `React` `Computer Vision`

🔗 **[View Project](https://github.com/IT24102884/animal-image-classification)**

---

### 🚜 JCB Equipment Rental & Management System

**Tech:** `Java` `Spring Boot` `Spring Security` `MySQL` `JPA` `Hibernate`
